# 防災チャレンジ（そば祭り防災コーナー用クイズ）

以下のファイル一式をまとめて（同じフォルダ内に）Vercelにアップロードして使う静的Webアプリです。ビルド不要（フォントのみGoogle Fontsを読み込みます）。

```
index.html        … 来場者用のクイズ本体
quiz-data.json     … 問題・アンケートのデータ（editor.htmlで編集）
editor.html        … スタッフ用の問題編集ツール（来場者には案内しない）
```

`index.html`は起動時に同じフォルダの`quiz-data.json`を読み込むため、**Webサーバー経由（Vercel等）でアクセスする必要があります**。ローカルでファイルをダブルクリックして開くと、ブラウザの制限で問題が読み込めません（確認したい場合は`editor.html`側の「ファイルを選択して読み込む」を使うか、簡易ローカルサーバーを立ててください）。

## Vercelへのアップロード方法（どちらでもOK）

### 方法A：ブラウザにドラッグ＆ドロップ（一番かんたん）
1. https://vercel.com にログイン（GitHubアカウント等でOK）
2. ダッシュボードの「Add New...」→「Project」→ 画面内の「Deploy without Git（フォルダをドラッグ）」を選択
3. `index.html`・`quiz-data.json`・`editor.html`が入ったこのフォルダごとドラッグ＆ドロップ
4. 数十秒でURLが発行されます（例：https://xxxx.vercel.app）

### 方法B：Vercel CLIを使う
```bash
npm i -g vercel
cd このフォルダ
vercel --prod
```

## クイズ問題の編集（quiz-data.json / editor.html）

来場者用の`index.html`は、同じフォルダにある`quiz-data.json`から問題データ（本編15問・地域限定の追加問題3問・アンケート）を読み込んで表示します。問題を見直したいときは`index.html`を直接編集する必要はありません。

### 編集手順
1. `editor.html`をブラウザで開く（ローカルでもVercel上でもどちらでも構いません。ローカルで開く場合は、`quiz-data.json`と同じフォルダに置いてください）
2. 「クイズ本編」「地域限定の追加問題」「アンケート」の3タブで、それぞれ問題の追加・編集・削除ができます
3. 編集が終わったら「JSONをダウンロード」を押し、`quiz-data.json`をダウンロードする
4. ダウンロードしたファイルで、Vercel上の`quiz-data.json`を差し替えて再アップロードする

`editor.html`自体は一般の来場者に案内しないでください（スタッフ専用ツールです）。

### 注意点
- `editor.html`は「クイズ本編・追加問題・アンケート」の内容をその場で書き換えられますが、**保存は「JSONをダウンロード」した時だけ**です。ブラウザを閉じると編集内容は失われるので、編集が終わったら都度ダウンロードしてください。
- クイズ本編・追加問題の増減は自由に行えます（Microsoft Forms側の設定変更は不要です。「各問正誤」は1つの欄にまとめて送る仕組みのため）。
- アンケートは選択式のみ対応しています。**アンケートの質問を追加・削除した場合は、Microsoft Forms側にもその分の質問欄（テキスト形式）を追加・削除し、`index.html`内の`MSFORM.surveyParams`に対応するパラメータ名を追記する必要があります**（下記参照）。

## 回答結果の集計（Microsoft Forms連携）

来場者が各自のスマホでQRコードから回答する運用を想定し、**回答結果画面に表示される「結果をアンケートに送信する」ボタン**から、値が入った状態のMicrosoft Formsを開けるようにしています。中身を確認して「送信」を押すだけで、Microsoft側のスプレッドシート（Excel）に自動で集計されます。

※ Googleフォームと違って、Microsoft Formsには外部サイトから“裏側で自動送信”する仕組みが公式には無いため、「内容が埋め込まれたリンクを開いて、最後に1回だけ送信を押してもらう」方式にしています。回答者がMicrosoftアカウントを持つ必要はありません（フォーム側を「リンクを知っている全員が回答可」に設定します）。

### 手順1：Microsoft Formsでフォームを作る
1. https://forms.office.com （個人のMicrosoftアカウントでもOK）にログインし、新しいフォームを作成
2. 以下の5つの質問を、**この順番で**「テキスト（記述式）」として追加
   1. 得点
   2. 満点
   3. 正答率
   4. 追加問題を含んだか
   5. 各問正誤
3. 右上の「…」→「設定」→「回答」で、**「組織外のユーザーも回答可能」「リンクを知っている全員が回答可能」** になっていることを確認（サインイン不要にする）

### 手順2：プレフィル入りURLを取得する
1. 右上の「…」メニュー →「プレフィル入りURLの取得」
2. 「プレフィルされた回答を有効にする」をON
3. 5つの質問それぞれに、区別しやすいダミー値を入れる（例：得点→`TESTSCORE` / 満点→`TESTTOTAL` / 正答率→`TESTRATE` / 追加問題を含んだか→`TESTEXTRA` / 各問正誤→`TESTDETAIL`）
4. 「プレフィルされたリンクを取得」をクリックし、表示されたURLをコピー

コピーしたURLは、次のような形になっています（実際はもっと長い英数字です）。
```
https://forms.office.com/r/AbCdEfGhIj?r111=TESTSCORE&r222=TESTTOTAL&r333=TESTRATE&r444=TESTEXTRA&r555=TESTDETAIL
```

### 手順3：`index.html` に値を書き込む
`index.html`内の `MSFORM` という設定箇所（`<script>`内、前半あたり）を、手順2で得たURLの情報に書き換えます。

```js
const MSFORM = {
  baseUrl: "https://forms.office.com/r/AbCdEfGhIj",   // ?より前の部分
  params: {
    score:  "r111",   // ダミー値 TESTSCORE を入れた項目のパラメータ名
    total:  "r222",   // ダミー値 TESTTOTAL を入れた項目のパラメータ名
    rate:   "r333",   // ダミー値 TESTRATE を入れた項目のパラメータ名
    extra:  "r444",   // ダミー値 TESTEXTRA を入れた項目のパラメータ名
    detail: "r555",   // ダミー値 TESTDETAIL を入れた項目のパラメータ名
  },
};
```
どのダミー値がどのパラメータ名（`r〜`）に対応しているかは、コピーしたURLの中で値を検索すれば分かります。書き換えたら保存して、Vercelに再アップロード（再デプロイ）してください。

未設定のまま（`YOUR_FORM_ID_HERE`のまま）の場合は、結果画面に送信ボタンは表示されません（後述の端末内控えだけが動作します）。

### アンケート項目をMicrosoft Formsに送る場合
アンケート（`quiz-data.json`内の`survey`）は、初期状態では送信されません（端末内控えのCSVには残ります）。Forms側にも送りたい場合は、以下を行ってください。

1. 先ほどのMicrosoft Formsに、アンケートの質問数だけ「テキスト（記述式）」の質問を追加する（`quiz-data.json`の`survey`にある質問と同じ内容・同じ順番がおすすめです）
2. もう一度「事前入力済み URL の取得」を開き、追加した質問にもダミー値（例：`TESTS1`、`TESTS2`…）を入力してリンクを取得
3. `index.html`内の`MSFORM.surveyParams`に、`quiz-data.json`の`survey[].id`（`s1`、`s2`…）をキーにして、対応するパラメータ名を追記する

```js
surveyParams: {
  s1: "r666",   // ダミー値 TESTS1 を入れた項目のパラメータ名
  s2: "r777",   // ダミー値 TESTS2 を入れた項目のパラメータ名
  s3: "r888",
},
```
アンケートの質問を`editor.html`で追加・削除した場合は、このFormsの質問欄と`surveyParams`の対応もあわせて見直してください。

## 電波が悪い場所向けの保険（端末内控え・CSV出力）

小黒川渓谷キャンプ場向かいの会場は電波が不安定な可能性があるため、**Microsoft Formsへの送信結果とは別に、回答した端末のブラウザ内にも自動的に結果を控えています**（スコア・正答率・各問正誤など）。参加者がその場でうまく送信できなくても、データ自体は端末に残ります。

会場のタブレット等、複数人が同じ端末で回答する運用の場合は、この端末内控えだけでも当日の集計に使えます。

### スタッフ用画面の開き方
サイトのURLの末尾に `?staff=1` を付けて開きます。
```
https://xxxx.vercel.app/?staff=1
```
画面左下に集計パネルが表示され、
- **CSVでダウンロード**：その端末に溜まった全回答をCSVファイルとして書き出せます（Excelでそのまま開けます）
- **端末内の控えを消去**：端末内のデータをリセットします（イベント終了後や、次回に備えてリセットしたいときに）

※ この端末内控えは「そのブラウザ・その端末だけ」のデータです。来場者が各自のスマホで回答した場合、その内容はその人のスマホの中にしか残らないため、複数端末をまたいだ集計には使えません。複数端末で確実に集計したい場合は、上記のMicrosoft Forms連携を必ず設定してください。

## 内容のカスタマイズ
- クイズの問題文・選択肢・正解・解説・出典、アンケートの内容は、すべて`quiz-data.json`にまとまっています。`editor.html`（上記参照）から編集するか、テキストエディタで直接`quiz-data.json`を書き換えても反映されます。
- 配色は`index.html`先頭の `<style>` 内、`:root { --navy: ... }` などの変数で一括変更できます。
